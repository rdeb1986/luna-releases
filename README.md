# Luna Photo Culling Studio — versões

Este repositório guarda só as versões prontas do **Luna Photo Culling Studio**
(instalador e pacotes de atualização). Não há código aqui.

- **Instalar:** baixe o `LunaPhotoCullingStudio-Setup-<versão>.exe` mais recente em
  [Releases](../../releases/latest) e execute.
- **Atualizar:** o próprio programa avisa quando há versão nova (botão de nuvem no topo da tela).
